# Customize Axis Labels in Syncfusion Blazor Chart

## Overview

This sample demonstrates how to customize axis labels in a Syncfusion [Blazor Chart](https://www.syncfusion.com/blazor-components/blazor-charts). The implementation focuses on chart axis label customization scenarios such as smart axis labels, multilevel labels, and custom label positioning. These features help improve chart readability when displaying large datasets, hierarchical categories, or densely packed labels. The sample provides practical examples for presenting business and analytical data with enhanced axis-label visualization.

## Key Features

- Demonstrates customization of chart axis labels using the Syncfusion Blazor Chart component.
- Shows smart axis label behavior to optimize label display when space is limited.
- Illustrates multilevel axis labels for grouping related categories under shared headers.
- Demonstrates axis label positioning options for improving chart presentation.
- Includes examples for displaying customized labels across different chart-axis configurations.
- Uses Blazor components and chart-axis settings to improve readability and organization of chart data.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `CustomAxisLabels.sln`

3. Restore all NuGet packages.
4. Build the solution.
5. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root.

```bash
cd how-to-customize-blazor-chart-axis-labels
dotnet restore
dotnet run
```

If the hosted Blazor solution requires running from a startup project, navigate to that project before execution.

```bash
cd Server
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
